## 与 4K 的关系

2048 和 4K 不是简单线性缩放：

- 4K 顶层第一项在 `(1986,1100)`；
- 2048 顶层第一项在 `(1200,427)`；
- 直接按分辨率比例换算对不上，说明 UI 布局/锚点随窗口模式变化。

因此不能把 4K 的 `ui_layout` 直接用于 2048，也不能把 2048 数据写进原来的
2560 `ui_layout`。

## 边界

- 目前只有南皮一座城、一次样本；
- 没验证靠近屏幕边缘时菜单是否自动翻转/偏移；
- 没确认锚点到底取城池格子中心还是名字文本框；
- 生产 `ui_layout` / `offsets` 没有修改。
