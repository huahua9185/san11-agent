# REA：4K 城池指令菜单坐标测量（2026-10-23）

## 结论

在 4K（3840×2160）下，右键**自己的城池**陈留，出现了真正的城池指令菜单：

```text
都市 / 軍事 / 人材 / 外交 / 計略 / 君主
```

单击「都市」后，二级子菜单展开。截图测量得到（客户区 = 屏幕坐标，原点
`(0,0)`）：

```

```

## 重要观察

- 之前点“平原”没有指令菜单，是因为**平原不是玩家城池**；右键只弹出情报
  菜单（詳細情報/所屬武將/勢力情報…）。
- 陈留是自己的城，右键才是完整指令菜单。
- 菜单在 4K 下并没有简单按 2560 的坐标乘 1.5：`ui_layout` 里旧的
  `city_top_menu x=-143` 与 4K 实测方向/位置不一致。
- 目前只测了一座城、一次样本；菜单是相对**城池格子**还是**名字文本框**
  定位，仍需换城验证。生产 `ui_layout` 没有修改。
