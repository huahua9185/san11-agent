# 阳光分班大屏（Python 复刻）

复刻中学"阳光分班"仪式现场的大屏：全体学生名牌先聚成一团随机翻滚，再当众逐个飞入 15 个班级方阵，
每个班实时显示人数与男女数，全程公开透明。

![流程] 待开始 → 随机中 → 派发中 → 分班完成

## 运行

```bash
python3 app.py                 # 默认 15 个班 / 855 名学生（随机名单），自动打开浏览器
python3 app.py --port 8080 --no-browser
```

浏览器打开 <http://127.0.0.1:8000>，快捷键：

| 键 | 作用 |
|---|---|
| `空格` / 点击 | 开始分班 / 重放动画 |
| `R` | 重新随机分班（换一份结果） |
| `E` | 导出分班名单 CSV |
| `F` | 全屏（投大屏用） |

鼠标悬停在任意名牌上，可看到"班级 · 姓名 · 性别 · 学号"。

## 用真实名单

CSV 至少要有姓名、性别两列（列名可用中文或英文），有成绩列会一并用于均衡：

```csv
姓名,性别,分数
张三,男,88
李四,女,91
```

```bash
python3 app.py --roster students.csv --classes 12 --title "XX中学七年级阳光分班"
```

只出结果、不放动画：

```bash
python3 app.py --roster students.csv --export 分班结果.csv
```

## 常用参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--classes` | 班级数 | 15 |
| `--students` | 随机名单人数（不带 `--roster` 时生效） | 855 |
| `--roster` | 真实名单 CSV | 无 |
| `--title` | 大屏标题 | 吴忠市第四中学七年级阳光分班 |
| `--seed` | 随机种子，便于复现同一结果 | 无（每次不同） |
| `--export` | 只导出 CSV，不启动服务 | 无 |

## 分班算法

`app.py` 里的 `allocate()`：男、女分别按成绩降序做**蛇形均分**（1→15 班、15→1 班交替），
同分先随机打乱、班级顺序也随机，最后班内座位再洗一次。结果满足三个均衡：

- **人数**：尽量均分，余数摊到前面的班（如 855 人 15 班 = 每班 57）；
- **男女比**：每班男女数最多相差 1；
- **平均分**：各班平均分差通常在 0.5 分以内。

跑一次就能看到：

```
1班 57 男31 女26 平均 71.78
2班 57 男30 女27 平均 71.99
...
```

## 结构

- `app.py` —— 名单生成 / 读取、均衡分班算法、CSV 导出，标准库 `http.server` 起本地服务（零依赖）。
- `index.html` —— 大屏渲染：1920×1080 虚拟画布等比缩放到任意屏幕，Canvas 绘制班级卡片与全部名牌，
  聚集 → 派发 → 落位三段动画。
